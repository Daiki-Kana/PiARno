# AR-Piano - 37-Key Paper Piano Kinematics & Vision Prototype (Minimal Monochrome Edition)

Webブラウザ上で動作する、実寸大37鍵ペーパー鍵盤対応のARピアノです。
スマートフォンのカメラ（超広角 Ultra Wide 対応）で机上のペーパー鍵盤と両手を捉え、高精度な打鍵判定とピアノ発音を実現します。

---

## 主な機能と特徴

1. **すっきりとした視界（骨格カメラ非表示 ＆ 白黒ミニマルUI）**
   - カメラ画面上では手の骨格線（ボーン・関節・タグ）を非表示にし、机上の鍵盤と演奏の視認性を最大化
   - 必要に応じて右上の「設定」パネルから骨格オーバーレイの表示/非表示を即座に切り替え可能
   - アプリ全体を洗練された白黒（モノトーン・ミニマリズム・グラスモーフィズム）デザインに一新

2. **実寸大37鍵ペーパー鍵盤対応 (C3〜C6)**
   - 22白鍵 ＋ 15黒鍵（3オクターブ＋高音C）の標準37鍵構成
   - 4隅ドラッグによる画角パース歪み（台形補正）の直感的な調整
   - 各鍵盤の押下ハイライトと純白のクリアな打鍵波紋エフェクト

3. **5秒タイマー式スマートキャリブレーション**
   - 「キャリブレーション (5s)」を押すと5秒のカウントダウンがスタート
   - カウント音（ピ・ピ・ピ・ポーン）と画面ガイドに合わせて両手10指を机上に配置
   - タイマー終了時に机の接触面（打鍵ゼロ点）を自動測定・登録

4. **超広角カメラ (0.5x / Ultra Wide) 自動優先対応 & カメラ切替**
   - スマホの超広角レンズ（0.5x / Ultra Wide）を自動検出して最広角で起動
   - ハードウェア最小ズーム強制適用 ＆ 4:3フルセンサー画角で広い視野を確保
   - 右上の「カメラ切替」ボタンで背面超広角・標準・前面カメラをワンタップ切替

5. **MediaPipe Tasks Vision + 1€ Filter + 運動学ステートマシン**
   - Wasm + GPU Delegate による低遅延・両手同時トラッキング（`numHands: 2`）
   - 1€ Filter によるジッター除去と、指先速度・屈曲角度・ヒステリシスによる高精度打鍵判定

6. **Web Audio API ポリフォニックシンセサイザー**
   - ピアノアコースティック倍音シミュレーションによる自然な減衰音

## スマートフォンでの起動方法

スマホのカメラアクセスには **HTTPS (Secure Context)** が必須です。

### 1. サーバー起動
```bash
npm start
```

### 2. スマホで接続
ターミナルに表示される **Cloudflare Tunnel の公開 HTTPS URL / QRコード** をスマホのカメラでスキャンして開きます。
（Wi-Fi同一ネットワーク経由の場合は `https://192.168.x.x:3443` でも接続可能です）

### 3. アプリ起動
ページを開くと確認画面なしで自動的にカメラが即座に起動し、37鍵オーバーレイが表示されます。
画面の任意の場所をタップすると音声が有効化されます。
